# 灯笼夜市

一款在浏览器中直接运行的横版平台跳跃小游戏。画面是剪纸灯会：夜色、灯笼、纸蛾和灯鬼。玩家操控一只剪纸精灵跳跃、收集符咒，并在三关中抵达终点。

不依赖游戏引擎，也不使用外部图片和音频。场景用 Canvas 绘制，音效用 Web Audio API 合成。

## 怎么玩

用浏览器打开 `index.html`，或用本地静态服务器打开项目目录。

| 操作 | 按键 |
| --- | --- |
| 开始 / 进入下一关 | Enter |
| 移动 | 方向键或 WASD |
| 跳跃 | 空格、W 或 ↑ |
| 重开当前关 | R |

掉出画面、碰到敌人或纸镖会回到本关出生点。收集的符咒会计入本关和通关结算。

## 内容

三关难度递进：

1. **入门灯巷**：缺口跳跃，认识纸蛾、灯鬼和纸镖。
2. **屋脊夜市**：沿单向屋檐上行，灯鬼会追近，纸偶会发射纸镖。
3. **灯海尽头**：踏脚更窄，敌人更快，其中一只灯鬼可以上下追击。

玩法包括：

- 重力、跳跃，以及实心平台与单向平台的碰撞
- 跟随角色平滑移动、并限制在关卡范围内的镜头
- 巡逻的纸蛾、发现玩家后追击的灯鬼、定时发射的纸镖
- 可收集的符咒、关卡终点、过场与通关画面
- 随收集进度变亮的夜色，以及视差背景和灯笼

## 技术实现

原生 HTML、CSS 与 JavaScript（ES Modules），画面画在一块 960×540 的 Canvas 上。

- `requestAnimationFrame` 驱动循环，帧间隔有上限，避免页面切出后角色一次移动过远
- 碰撞使用轴对齐包围盒：先处理水平方向，再处理带重力的垂直方向；单向平台只在从上方落下时承接
- 关卡以数据描述平台、敌人、符咒、灯笼、出生点与终点，开局时复制一份再运行，重开不会改动原始配置
- 输入在按键按下时记录一次，避免按住跳跃键连续起跳；切出页面时清空按键状态
- 跳跃、收集、受击、发射和过关使用振荡器合成短音效

## 项目结构

- `index.html` — 页面入口与画布
- `css/style.css` — 页面排版
- `js/main.js` — 游戏循环、场景切换与音效
- `js/input.js` — 键盘输入
- `js/player.js` — 移动、跳跃与角色状态
- `js/physics.js` — 碰撞
- `js/entities.js` — 敌人、投射物、符咒与终点判定
- `js/levels.js` — 三关配置
- `js/render.js` — 场景、角色与界面绘制
